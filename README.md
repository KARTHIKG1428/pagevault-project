# PageVault Elite – OpenShelf Campus Exchange

**Presented by:** G. Karthik

PageVault Elite is a full-stack web application that helps students share, search, borrow, and exchange textbooks within their campus.

### Features
- Student registration and secure login.
- Search and filter textbooks.
- Add and manage book listings.
- Borrow requests and approval system.
- Wishlist and borrowing history.
- Smart book recommendations.
- ISBN book information lookup.
- Seven-day borrowing period.

### Technologies
HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.

### How to Run
```bash
npm install
npm run seed
npm run dev
```

Open `http://localhost:5000` in your browser.

**Goal:** Make textbook sharing easy, affordable, and accessible for every student.
